Privacy Policy

Padel Perfecto is a personal publishing tool operated by its owner.

  • Data accessed: basic profile information of the owner's connected account, used only to confirm which account is connected.
  • Data stored: an access token for the owner's account, held by the connection provider (Composio), used only to publish the owner's videos. No other personal data is collected.
  • Data shared: none. The tool does not access, store or share data about any other user.
  • Deletion: the owner can revoke access at any time in the platform's app permission settings.
