# Padel Perfecto

Animated padel coaching videos for TikTok and Instagram, generated from scene files and rendered with Remotion.

- `content/scenes/*.json`: one video each. `node validate.mjs` checks them, and `node render.mjs [id]` renders to `out/`.
- `docs/`: public site (GitHub Pages) with the privacy and terms pages for the TikTok app.
- See `CLAUDE.md` for the weekly batch procedure.
